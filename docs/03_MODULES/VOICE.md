# NOVIA Voice

Statut : **DECIDED — module optionnel/premium ; SPECIFIED PARTIEL — démo visuelle ; non connecté**. Sources : S2/S3.

## Objectifs envisagés

Répondre aux appels, utiliser des FAQ autorisées, qualifier, collecter les coordonnées, réserver, déplacer/annuler lorsque fiable, transférer à un humain et alimenter le CRM. Modes possibles : tous les appels, appels manqués, hors horaires.

Mesure envisagée : appel → prospect → rendez-vous → client → revenu attribué. Aucune performance ou disponibilité 24/7 réelle n'est prouvée.

## Démonstration prévue

Côté cliente : invitation à appeler ouvrant une simulation explicitement présentée comme telle. Côté pro : appels reçus/traités, rendez-vous créés, transferts humains, mode et interrupteur visuel. Le libellé doit indiquer que l'état « actif » est simulé.

Le bouton ne compose pas un vrai numéro et l'interrupteur ne connecte rien. Aucun numéro français, opérateur, forfait, prompt vocal complet ou système d'enregistrement n'est choisi.

## À valider avant connexion

FAQ réelle approuvée, source des disponibilités, permissions de modification, limites d'autonomie, transfert humain, erreurs et disponibilité réelle. Vérifier ensuite les capacités GHL ou d'un autre fournisseur, les coûts et les règles applicables aux appels ; aucune affirmation de conformité ni de disponibilité fournisseur n'est faite ici.
