# NOVIA Pilates — configuration initiale

Statut : **DECIDED — première niche commerciale Pilates / Pilates Reformer ; configuration détaillée À CONCEVOIR**. Source : S2.

## Positionnement connu

Pilates est la première niche commerciale prévue. Le pilote Nails précède ce déploiement pour tester l'expérience et les besoins opérationnels. Le cœur NOVIA doit rester réutilisable ; les règles spécifiques d'une onglerie ne sont pas automatiquement celles d'un studio.

## Fiche initiale

| Élément | Valeur / état |

| Verticale commerciale | Pilates / Pilates Reformer |
| Business pilote Pilates | Aucun identifié dans les sources accessibles |
| Identité, coordonnées, horaires | À RENSEIGNER |
| Prestations, essais, cours, ressources, capacité | À CONCEVOIR avec un studio réel |
| Tarifs, packs, abonnements, règles d'essai | À CONFIRMER ; aucune offre inventée |
| Annulation, absence, liste d'attente | À VALIDER par verticale |
| Réservation, CRM, suivi, récurrence, revenu | Modules NOVIA à adapter |
| Outils existants et source d'agenda | INCONNUS |

W02 porte le nom « Rendez-vous / essai réservé » dans le cœur ; cela ne définit ni prix d'essai ni durée ni mécanisme de conversion. W05 à W12 restent à concevoir. Aucun cours, capacité Reformer, taux de conversion ou revenu cible n'est fixé.

Prochaine préparation utile : entretien métier et comparaison des besoins avec le modèle générique `service` / `appointment` / `customer`, avant tout développement spécifique Pilates.
